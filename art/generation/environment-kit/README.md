# Quarantined environment-kit experiment

This directory preserves one and only one coordinated environment-kit generation attempt. It is evidence for improving Cinderwake's asset pipeline, not production art.

## Reproduce the deterministic boundary

The image generator is nondeterministic, so the raw PNG, exact prompt, artifact ID, source hashes, and generated bytes are immutable. Everything after that boundary is deterministic:

```bash
node scripts/prepare-environment-kit.mjs \
  --input art/generation/environment-kit/candidates/environment-kit-v1.png \
  --output art/generation/environment-kit/prepared/environment-kit-v1.png

node scripts/assess-environment-kit.mjs
```

The assessor runs the preparation twice in isolated temporary directories and requires both outputs to equal the committed prepared hash. It measures the raw 3 × 2 layout, literal and tolerant chroma coverage, six-component recovery, component gaps, required cell padding, prepared safe borders, common foot contact, runtime silhouettes, doorway aperture, and collision-footprint proxies. It then sends five deliberately damaged copies through the same prepared assessor: opaque matte, border bleed, cross-cell bridge, floating foot, and needle-thin contact.

The committed report and visual sheets live under `evidence/environment-kit-v1/`. `runtime-scale-contact-sheet.png` is the important visual check: it places every recovered component at its declared logical height over the current game floor rather than letting every source cell look equally large.

## Honest result

The candidate is **rejected and quarantined**:

- the raw image passes 4/6 structural checks but fails literal `#ff00ff` and 12% equal-cell padding;
- deterministic preparation recovers all six silhouettes, but the doorway passes only 63 prepared pixels at the narrowed arch, below the minimum collision-readable aperture;
- five of six prepared semantic cells pass their mechanical proxies, but zero are integration-safe because they share one rejected source and visual contract;
- all 5/5 paired bad controls are detected;
- visual review likes the coordinated camera, materials, warm light, readable silhouettes, and runtime-scale contact sheet, but rejects source-scale lanterns, the non-repeatable gate wall, and residual spill flecks.

No production source, atlas, manifest, gameplay code, snapshot, or runtime test references this candidate.
